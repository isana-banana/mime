# Kebijakan Ukuran Batch Audit Manual INTISARI V4

Mulai batch berikutnya, ukuran batch resmi audit manual Tahap 1 adalah **1.000 ID unik**.

## Cara pelaksanaan
- Pilih hanya ID yang belum pernah diaudit pada batch sebelumnya.
- Satu batch resmi berisi maksimal 1.000 ID baru; bila sisa antrean kurang dari 1.000, gunakan seluruh sisanya.
- Untuk menjaga ketelitian, satu batch resmi boleh dikerjakan dalam 10 subkelompok internal masing-masing 100 ID.
- Setiap percakapan harus dibaca utuh, bukan diputuskan hanya dari kata kunci atau tanda otomatis.
- Nilai topik utama. Penyebutan internet, ponsel, aplikasi, situs, atau YouTube secara sekilas tidak otomatis membuat percakapan luring menjadi topik digital.
- Jangan mengubah isi atau kata ganti pada Tahap 1. Tahap ini hanya memutuskan apakah topik percakapan masuk cakupan.
- Catat keputusan hanya setelah percakapan benar-benar diperiksa. Baris antrean yang belum diperiksa tidak boleh dihitung sebagai hasil audit.
- Periksa ID duplikat lintas batch sebelum menyimpan hasil.
- Semua hasil tetap `training_ready=false` sampai ketiga tahap selesai dan mendapat persetujuan pengguna.

## Posisi saat kebijakan diubah
- ID unik yang sudah diperiksa: 318 dari 1.680.
- Sisa antrean campuran: 1.109.
- Sisa antrean ambigu saja: 253.
- Total sisa pemeriksaan manual Tahap 1: 1.362.
- Target batch resmi berikutnya: 1.000 ID baru.
